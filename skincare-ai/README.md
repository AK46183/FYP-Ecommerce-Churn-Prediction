# skincare-ai (standalone module)
MINAYSH Skin Assistant: LLM + RAG + products + safety. Abhi MINAYSH website se alag hai.

Chalana:
  pip install -r requirements.txt
  python test_modules.py      # bina API key ke test
  python chat_cli.py          # terminal chatbot (key chahiye)

Baad mein: Node `/api/chatbot` is service ko call karega (FastAPI wrapper), phir frontend chat widget.
